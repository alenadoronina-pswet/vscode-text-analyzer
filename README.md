# Статистика текста

Плагин для Visual Studio Code, который анализирует текст открытого документа или выделенный фрагмент.

**Автор:** Доронина Алена Андреевна  
**Группа:** М3117  
**Язык программирования:** JavaScript  
**Версия VS Code:** 1.74.0 или новее

## Возможности

- Подсчёт символов, слов и строк.
- Подсчёт уникальных слов без учёта регистра.
- Определение пяти самых частых слов с количеством повторений.
- Анализ основного выделения или всего документа, если выделения нет.
- Вывод результатов в панели «Вывод».
- Обработка пустого документа и отсутствия открытого текстового редактора.

Плагин не изменяет исходный текст.

## Правила подсчёта

Словом считается последовательность букв. Регистр не учитывается: «Кот» и «кот» считаются одним словом. Цифры и знаки препинания словами не являются. Дефис разделяет слова.

Символы считаются по кодовым точкам Unicode, включая пробелы и переводы строк. Пустой документ содержит 0 строк. Перевод строки в конце документа добавляет пустую строку.

Самые частые слова располагаются по убыванию количества повторений. При одинаковой частоте используется алфавитный порядок.

## Запуск

1. Скачать проект и открыть папку `text-stats-lab` в настольном VS Code.
2. Перейти в раздел **Run and Debug**.
3. Выбрать конфигурацию **«Запустить плагин»** и нажать кнопку запуска или **F5**.
4. В открывшемся окне **Extension Development Host** создать или открыть текстовый файл.
5. При необходимости выделить фрагмент для анализа.
6. Открыть палитру команд: **Cmd+Shift+P** на macOS или **Ctrl+Shift+P** на Windows/Linux.
7. Выполнить команду **«Статистика текста: анализировать»**.
8. Посмотреть результат в канале **«Статистика текста»** панели **«Вывод»**.

Дополнительные библиотеки для запуска расширения не требуются.

## Пример

Для текста `Кот кот дом` без переноса строки в конце результат будет следующим:

```text
Область: весь документ
Символов: 11
Слов: 3
Строк: 1
Уникальных слов: 2
Самые частые слова:
кот: 2
дом: 1
```

## Структура проекта

- `package.json`: описание расширения и команды.
- `extension.js`: взаимодействие с VS Code и вывод результатов.
- `analyzer.js`: обработка текста и подсчёт статистики.
- `.vscode/launch.json`: настройки запуска.
- `test/analyzer.test.js`: автоматические тесты анализатора.
- `docs/`: документация и отчёт.

## Тестирование

Для запуска автоматических тестов необходим Node.js версии 18 или новее. В терминале папки проекта выполнить:

```bash
npm test
```

Для запуска самого плагина отдельная установка Node.js не требуется.
