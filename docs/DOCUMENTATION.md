# Документация плагина «Статистика текста»

## Назначение

Плагин анализирует текст в Visual Studio Code. Если пользователь выделил фрагмент, обрабатывается только он. Если выделения нет, обрабатывается весь открытый документ.

Результат появляется в панели «Вывод»: количество символов, слов, строк, уникальных слов и список пяти самых частых слов. Исходный текст остаётся без изменений.

## Файлы проекта

- `package.json`: название расширения, поддерживаемая версия VS Code и объявление команды.
- `extension.js`: регистрация команды, получение текста и вывод результата.
- `analyzer.js`: подсчёт статистики.
- `.vscode/launch.json`: конфигурация запуска плагина.
- `test/analyzer.test.js`: тесты функции анализа.

## Подключение к VS Code

Расширение работает через API VS Code, доступное в модуле `vscode`. Команда `textStats.analyze` объявлена в `package.json` и отображается в палитре под названием «Статистика текста: анализировать».

При активации расширения вызывается функция `activate(context)`. Она создаёт канал вывода и связывает команду с обработчиком. Код плагина выполняется в Extension Host.

## Получение текста

Обработчик команды в `extension.js` получает активный редактор через `vscode.window.activeTextEditor`.

Если редактора нет, появляется сообщение «Сначала открой текстовый файл», и выполнение заканчивается.

Если редактор открыт, проверяется `editor.selection`. При наличии выделения метод `getText(selection)` возвращает выбранный фрагмент. Без выделения вызывается `getText()`, который возвращает весь документ. При нескольких выделениях используется основное.

## Функция analyzeText(text)

Функция находится в `analyzer.js`. На вход она получает строку, а возвращает объект со следующими полями:

| Поле | Содержимое |
|---|---|
| `characters` | Количество символов |
| `words` | Количество слов |
| `lines` | Количество строк |
| `unique` | Количество уникальных слов |
| `top` | Массив пар «слово, количество повторений» |

Обработка выполняется в следующем порядке:

1. Текст переводится в нижний регистр.
2. Регулярное выражение выделяет слова и сохраняет их в массив.
3. Цикл подсчитывает повторения слов с помощью `Map`.
4. Записи сортируются по убыванию частоты. При одинаковой частоте используется алфавитный порядок.
5. Из отсортированного массива выбираются первые пять записей.
6. Формируется объект с результатами.

В `Map` ключом служит слово, а значением является число повторений. Например, для текста `Кот кот дом` сохраняются записи `кот: 2` и `дом: 1`.

## Правила подсчёта

Словом считается последовательность букв Unicode. Регистр не учитывается. Цифры и знаки препинания словами не являются. Дефис и подчёркивание разделяют слова.

Количество символов включает пробелы и переводы строк. Подсчёт выполняется по кодовым точкам Unicode, поэтому некоторые составные эмодзи могут учитываться как несколько символов.

При подсчёте строк обрабатываются переносы LF, CRLF и CR. Пустой текст содержит 0 строк. Перенос в конце текста добавляет пустую строку.

## Вывод результата

Обработчик получает результат `analyzeText` и записывает его в канал «Статистика текста». Перед каждым анализом предыдущий вывод очищается.

Если в тексте нет слов, выводится сообщение «Слов не найдено». Команда и канал добавлены в `context.subscriptions`, чтобы VS Code освободил их при выгрузке расширения.

## Проверка расчётов

В файле `test/analyzer.test.js` проверяются:

- пустой текст;
- частоты слов и обработка регистра;
- Unicode и переносы строк;
- цифры, пунктуация и дефисы;
- сортировка и ограничение списка пятью словами.

Для запуска тестов нужен Node.js 18 или новее. Команда выполняется в папке проекта:

```bash
npm test
```

## Ограничения

Плагин анализирует текст по указанным правилам и не учитывает синтаксис языков программирования. Обработка выполняется синхронно, поэтому расширение предназначено для небольших документов.
